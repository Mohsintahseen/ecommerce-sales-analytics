# Cleaned data (not included)

`sales_clean.csv` (1,044,848 rows, about 124 MB) is produced by the `Export_Sales` query in `power_query/`.
It is a modified adaptation of the CC BY 4.0 dataset: overlapping rows removed, rows classified, text trimmed,
and columns added. It is not stored in the repository because of its size; rebuild it with the steps in the main README.
